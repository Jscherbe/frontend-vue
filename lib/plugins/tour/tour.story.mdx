# Tour Plugin

The Tour plugin allows configuring an app-wide guided tour that leverages `UluModal` and `@floating-ui/vue`. Register the plugin, and use the global API (or composable) to start step-by-step onboarding flows.

## Installing the plugin

Example `./src/main.js`

```js
import UluTour from "@ulu/frontend-vue/plugins/tour/index.js";

//...

app.use(UluTour);
```

To display the tour, you must include the `UluTourDisplay` component somewhere in your application root (e.g. `App.vue`):

```html
<template>
  <div id="app">
    <router-view />
    <UluTourDisplay />
  </div>
</template>
```

## Creating a Tour

A tour is defined as an object containing a `name` and an array of `steps`. You can also define global `modalProps` or `popoverProps` on the root tour object to apply them to all steps by default.

```js
const demoTour = {
  name: 'demo-tour',
  popoverProps: { modifiers: 'large' }, // Global popover styling for all steps
  steps: [
    {
      title: 'Welcome!',
      content: 'This step is a modal because it has no target element. Click next to continue.',
      modalProps: { size: 'small' } // Step-specific override
    },
    {
      target: '#step-1-btn',
      title: 'First Feature',
      content: 'This points to a simple button.',
      placement: 'bottom'
    }
  ]
};
```

### Step API Structure

Each step object can accept the following properties:

*   **`target`**: *(String)* The CSS selector for the target element. If omitted, the step renders as a centered modal.
*   **`title`**: *(String)* The title text for the step.
*   **`content`**: *(String)* The body content text for the step.
*   **`contentComponent`**: *(Object)* A Vue component to replace only the text content (keeps the modal/popover shell and default footer intact).
*   **`component`**: *(Object)* A Vue component to completely replace the outer wrapper (bypasses modal/popover entirely).
*   **`componentProps`**: *(Object)* Props to bind to `contentComponent` or `component`.
*   **`hideFooter`**: *(Boolean)* If true, hides the default tour footer (Next/Back/Close buttons). Useful if you want the standard text but no buttons.
*   **`placement`**: *(String)* Floating UI placement string (e.g. `'bottom'`, `'right'`).
*   **`highlight`**: *(Boolean)* If true, darkens the backdrop around the target element.
*   **`modalProps`**: *(Object)* Props to pass to the modal (only applies if `target` is omitted).
*   **`popoverProps`**: *(Object)* Props to pass to the popover (only applies if `target` is present).
*   **`onEnter`**: *(Function)* An async hook called before the step is rendered.

## Starting the Tour

You can control the tour programmatically using the `useTour` composable:

```html
<template>
  <button @click="startTour">Start Tour</button>
</template>

<script setup>
  import { useTour } from "@ulu/frontend-vue";

  const { api } = useTour();

  const startTour = () => {
    api.start(demoTour);
  };
</script>
```

Alternatively, you can use the global API:

```js
this.$uluTour.start(demoTour);
this.$uluTour.next();
this.$uluTour.prev();
this.$uluTour.stop();
```

## Custom Components & Layouts

If you need custom designs, the plugin supports two levels of control:

### 1. Custom Inner Content (`contentComponent`)

Use `contentComponent` if you want to render an image, form, or custom layout inside the step, but want to **keep** the default popover/modal wrappers and the Next/Back footer buttons.

```html
<template>
  <div style="text-align: center;">
    <img src="/logo.png" />
    <p>This is my custom graphic step.</p>
  </div>
</template>
```

### 2. Full Wrapper Takeover (`component`)

Use `component` if you want to bypass the `<UluModal>` and `<UluPopoverContent>` wrappers entirely. This allows you to build custom off-canvas drawers, alert banners, or custom absolute-positioned panels. 

You are responsible for your own positioning, styling, and wiring up the Next/Back buttons via `useTour()`.

```html
<template>
  <div class="my-custom-floating-drawer">
    <h3>Custom Design</h3>
    <!-- Wire up your own buttons -->
    <button @click="api.next()">Got it!</button>
  </div>
</template>

<script setup>
  import { useTour } from "@ulu/frontend-vue";
  const { api } = useTour();
</script>
```
